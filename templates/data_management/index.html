The FAIR Data Registry records where research data came from: for each file, its hash and where it is held, the code run that made it, the inputs that run read, the sources the data was taken from, and who made it. Its pages are for browsing what is registered; each data product's page shows its provenance as a graph and offers it as an RO-Crate. Its REST API is what the FAIR Data Pipeline's command-line tool and language APIs use to register and read it.
